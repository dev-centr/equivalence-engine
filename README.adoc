= Equivalence Engine

DAG-based equivalence engine: shortest-path resolution across implementations, tool calls, and custom mappings via SDL rulesets.

== About The Project

The core engine for the Equivalence Adaptation Ecosystem, maintained by link:https://github.com/dev-centr[dev-centr].

== Installation

=== Homebrew (macOS/Linux)

[source,bash]
----
brew tap dev-centr/tap
brew install equivalence-engine
----

=== Winget (Windows)

[source,powershell]
----
winget install dev-centr.EquivalenceEngine
----

== Usage

=== CLI domain (DevCentr)

Resolve an install command for a tool and host context:

[source,bash]
----
equivalence-engine --domain cli \
  --rules-repo https://github.com/dev-centr/equivalence-rules-cli \
  --to linux/nix/default gh
----

Prefer immutable Nix installs by default; pass `--prefer-mutable` to favor winget/brew/apt.
